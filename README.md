<details>
<summary><b>🔍 Click to see detailed notes on "Why Parcel?"</b></summary>

I learned that **Parcel** is a "Beast" that does:
1.  **HMR (Hot Module Replacement):** Updates the page without refreshing.
2.  **File Watching:** Rebuilds automatically when I save.
3.  **Minification:** Removes whitespace to make files lighter.
4.  **Dev Server:** Hosts the app locally.
</details>

<details>
<summary><b>📦 Click to see notes on package-lock.json</b></summary>

- **package.json:** The Menu (Approximate version `^`).
- **package-lock.json:** The Receipt (Exact version frozen).
- **Critical:** This file locks dependencies to ensure the app works the same on every machine.
</details>

<details>
<summary><b>🚫 Click to see notes on .gitignore</b></summary>

- We **never** push `node_modules` to GitHub because it is too heavy and can be regenerated.
- `package-lock.json` and `package.json` are enough to recreate `node_modules`.
</details>
